Software

Where our robot code, this website and our simulation tools live.

Robot

The robot code controls the robot. During Auto, the code runs pre-programmed paths; in tele-op it binds controller input to actions on the robot. The source is on GitHub, and WPILib is available from its official releases page.

Robot code on GitHub

Website

This website is a static site with no build step: plain HTML, one stylesheet and a small script. Anyone on the software team can update it with a text editor. The production site is spartabots.org.

Website source on GitHub

Simulation

Simulation lets us create auto paths and test software without the physical robot. We use AdvantageScope, which connects to WPILib.
